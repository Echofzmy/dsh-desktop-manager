# 归档会话后自动关闭再允许永久删除

## 决策

归档会话是生命周期转换，不只是列表过滤。持久化归档提交后，每个 Web runtime 在观察到变更时释放自己拥有的 live session handle。永久删除仍然拒绝运行中的会话，但已归档且处于 idle 状态的会话可以在外部 runtime 完成生命周期释放时删除。

## 原因

用户理解的关闭和归档都意味着不再使用该会话。要求用户定位并停止不可见的 Web runtime，把实现层的 ownership 细节暴露给了用户，也使归档流程无法正常完成。运行中的会话仍然受到保护，因为删除其持久化日志可能与新的写入发生竞态。

## 验证

Host workspace 测试、GUI 测试、类型检查和 Web replay 均覆盖该转换。replay 通过 84 个文件、285 个测试，另有 15 个测试跳过。
